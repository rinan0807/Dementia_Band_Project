# Dementia_Band_Project

**About**: This project is to help the caretakers of dementia patients. This wearable device alerts a caretaker when their dementia patient goes out of a predetermined safe zone. This ensures the caretaker is not always worried about the patient.

Description of the contents of each folder:


**CODE Folder** contains all software and programming files required for the dementia band. This includes the baud test code, the diagnostic code for testing invidual components such as the sms or gps and the final code with the geo-fence function. It also includes libraries used for the band.

**CAD Folder**: Contains all 3D design and mechanical files related to the physical structure of The dementia band. This includes enclosure designs, wearable sensor mounts.  CAD software such as FreeCAD The folder may also include STL files for 3D printing and technical dimension drawings.

**REFERENCE DETAILS Folder**: Contains circuit diagrams, wiring schematics and component datasheets. This folder also includes a finalized bill of materials. 

**Documentation Folder**: Contains the schematic pictures and building guide to the project
